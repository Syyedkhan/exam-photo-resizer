IBPS Photo Requirements 2026 (Official Specifications)

IBPS (Institute of Banking Personnel Selection) conducts exams for PO, Clerk, SO, and RRB across India. Every applicant must upload a photo, signature, thumb impression, and handwritten declaration. Each document has strict size and dimension requirements. If any document does not match, the application gets rejected. This tool helps you get all documents exactly right.

IBPS Photo Size & Dimensions

  • Photo dimensions: 200 x 230 pixels
  • Photo file size: 20 KB to 50 KB
  • Format: JPG or JPEG
  • Background: Plain white or light
  • Photo age: Recent (within 3 months)

IBPS Signature Requirements

  • Signature dimensions: 140 x 60 pixels
  • Signature file size: 10 KB to 20 KB
  • Ink color: Black ink on white paper
  • Important: Signature in CAPITAL LETTERS is NOT accepted

IBPS Thumb Impression Requirements

  • Thumb dimensions: 240 x 240 pixels
  • Thumb file size: 20 KB to 50 KB
  • Which thumb: Left thumb impression
  • Ink color: Black or blue ink on white paper

IBPS Handwritten Declaration Requirements

  • Declaration dimensions: 800 x 400 pixels
  • Language: English, handwritten
  • Important: NOT in CAPITAL LETTERS
  • Text: As per IBPS notification

Common Mistakes to Avoid

  • Uploading a photo with dark or colored background

  • File size above 50 KB — rejected
  • Old photo (more than 3 months) — rejected

IBPS photo should be 200x230 pixels with file size 20 KB to 50 KB in JPG/JPEG format.
